EXP. 9: Pipeline Creation using script
Steps & Commands (Copy-Ready)
1. Procedure in Jenkins
Under General, provide a description of the project.

Under Build triggers, configure build triggers of your choice.

Under Advanced project option / Definition, choose Pipeline script, paste the pipeline script below, and click Apply and Save.
pipeline script:

pipeline {
  agent any
  tools {
    maven 'MAVEN-HOME'
  }
  stages {
    stage('git repo & clean') {
      steps {
        //bat "rmdir /s /q mavenjava"
        bat "git clone provide your github link"
        bat "mvn clean -f mavenjava"
      }
    }
    stage('install') {
      steps {
        bat "mvn install -f mavenjava"
      }
    }
    stage('test') {
      steps {
        bat "mvn test -f mavenjava"
      }
    }
    stage('package') {
      steps {
        bat "mvn package -f mavenjava"
      }
    }
  }
}
```[cite: 116]
