Common SSH errors and solutions
Error	Solution
Permission denied (publickey)	Verify the correct .pem file and username
Connection timed out	Check Security Group port 22 and instance status
Host unreachable	Check public IP and network configuration
Bad permissions	Restrict private key file permissions
