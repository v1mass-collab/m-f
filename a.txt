Q2. Jenkins Scripted Pipeline – CI/CD Automation (25 Marks)
Aim
Create a Jenkins Scripted Pipeline for OLTRS that clones GitHub source code, builds and tests the application using Maven, creates a Docker image and pushes it to Docker Hub.
Step 1: Configure Jenkins prerequisites
Install or verify:
- Git plugin
- Pipeline plugin
- Docker Pipeline plugin (if using its Docker DSL)
- Maven installation
- JDK installation
Go to:

Manage Jenkins → Tools

Configure Maven with the name:
Maven3


Step 2: Configure Docker Hub credentials
Go to:

Manage Jenkins → Credentials → System → Global credentials → Add Credentials

Select:
- Kind: Username with password
- Username: Your Docker Hub username
- Password: Docker Hub access token
- ID: dockerhub-credentials
Use an access token rather than your Docker Hub account password.
Step 3: Create the Jenkins Pipeline
Create a new Pipeline item named:
OLTRS-CI-CD


Paste the following Scripted Pipeline:

node {

    def dockerImage

    stage('Checkout') {
        git branch: 'master',
            url: 'https://github.com/archanareddyse/OLTRS.git'
    }

    stage('Maven Build') {
        def mvn = tool name: 'Maven3',
                         type: 'hudson.tasks.Maven$MavenInstallation'

        env.PATH = "${mvn}/bin:${env.PATH}"

        sh 'mvn clean package'
    }

    stage('Test') {
        sh 'mvn test'
    }

    stage('Docker Build') {
        dockerImage = docker.build(
            'YOUR_DOCKERHUB_USERNAME/oltrs:latest'
        )
    }

    stage('Docker Push') {
        docker.withRegistry(
            'https://index.docker.io/v1/',
            'dockerhub-credentials'
        ) {
            dockerImage.push()
        }
    }
}



Replace YOUR_DOCKERHUB_USERNAME with your actual Docker Hub username.

For Windows Jenkins agents, replace sh with bat and configure the Docker CLI and Maven on that agent.
Step 4: Configure GitHub Webhook
Open your GitHub repository:

OLTRS → Settings → Webhooks → Add webhook

Configure:
Field	Value
Payload URL	http://<JENKINS-PUBLIC-URL>/github-webhook/
Content type	application/json
Events	Just the push event
Active	Enabled

In Jenkins, enable:

GitHub hook trigger for GITScm polling

under the job's Build Triggers.

A public, reachable Jenkins URL is required. A normal localhost address cannot receive GitHub webhooks.
Step 5: Execute and verify
Click:

Build Now

Open:

Build → Console Output

Verify that these stages complete:
1. Checkout
2. Maven Build
3. Test
4. Docker Build
5. Docker Push
Check Docker Hub to confirm that the image has been pushed.
